# THE VOID — The Archive of the Human Mind

واجهة أولية مستقلة مبنية بـ HTML/CSS/JavaScript دون إطار عمل أو مفاتيح سرية.

## التشغيل
افتح `index.html` مباشرة أو شغّل خادمًا محليًا:
`python -m http.server 8000`

## النشر على GitHub Pages
المستودع يُنشر من خلال GitHub Actions عند رفع الملفات إلى الفرع `main`.

## ملاحظات
- اللغة الافتراضية عربية وواجهة RTL، مع تبديل إنجليزي أساسي.
- تقدم الدروس التجريبي محفوظ محليًا في المتصفح.
- محتوى الأرشيف الحالي هيكل أولي؛ لا تُعرض ادعاءات تاريخية أو نفسية بلا مصادر موثقة.
- لوحة الإدارة والمحتوى البحثي الموسع ومزامنة الحساب مراحل لاحقة.
